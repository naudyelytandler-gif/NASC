# sist robo

Projeto pessoal de sistema de robô. Este repositório está começando agora — a
estrutura e a documentação serão preenchidas aos poucos.

## Sobre

O **NASC** é um projeto de aprendizado para desenvolver um sistema de robô do
zero, acompanhando cada etapa — do planejamento inicial até o código funcional.
A ideia é evoluir o repositório de forma incremental e organizada.

## Status

🚧 Em construção — primeiros passos do projeto.

## Como contribuir

1. Crie uma branch a partir da `main` (ex.: `git checkout -b minha-melhoria`).
2. Faça suas alterações e um commit descritivo.
3. Envie a branch (`git push -u origin minha-melhoria`) e abra um Pull Request.
